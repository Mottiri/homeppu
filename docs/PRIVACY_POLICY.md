# プライバシーポリシー

ほめっぷ（以下「本アプリ」）は、ユーザーの個人情報を適切に取り扱い、保護することを重要な責務と考えています。本ポリシーでは、本アプリにおける情報の取り扱いについて説明します。

## 1. 取得する情報
本アプリは、以下の情報を取得する場合があります。
- ユーザー登録情報（メールアドレス、表示名、ユーザーID）
- プロフィール情報（プロフィール画像、自己紹介、ヘッダー画像等）
- 利用情報（投稿内容、コメント、リアクション、サークル参加情報、タスク・目標情報、問い合わせ内容等）
- 端末情報（端末の種類、OS、アプリバージョン、識別子、IPアドレス等）
- 通知関連情報（FCMトークン等）
- 課金関連情報（サブスクリプション状態、購入関連イベント）

取得する情報の範囲は、サービス提供に必要な範囲に限定します。

## 2. 利用目的
取得した情報は、以下の目的で利用します。
- 本アプリの機能提供および運用
- ユーザー認証、本人確認、不正利用防止
- お問い合わせ対応
- 不具合調査、品質向上、利用状況分析
- プッシュ通知配信
- 広告配信および効果測定
- サブスクリプション管理、課金状態反映
- AI機能（投稿生成、モデレーション補助等）の提供

## 3. 第三者提供
取得した情報を、ユーザーの同意なく第三者に提供することはありません。  
ただし、以下の場合を除きます。
- 法令に基づく場合
- 人の生命、身体または財産の保護に必要な場合
- サービス提供に必要な範囲で外部サービス事業者へ委託する場合

## 4. 外部サービスの利用
本アプリでは、以下の外部サービスを利用する場合があります。
- Firebase（Google LLC）
  - 認証、データベース、ストレージ、通知配信、分析運用
- Google AdMob（Google LLC）
  - 広告配信および効果測定
- RevenueCat（RevenueCat, Inc.）
  - サブスクリプション状態管理
- Google Play Billing（Google LLC）
  - 定期購入の決済処理
- Google Gemini / OpenAI API
  - AI機能の提供（投稿生成、モデレーション補助等）
- Google Sheets（Google LLC）
  - 問い合わせ対応に関する運用連携

各サービス提供者のプライバシーポリシーは、各社の案内をご確認ください。

なお、AI機能により生成される投稿・返信等の内容について、運営者は正確性、完全性、有用性等を保証するものではありません。

## 5. データの保存期間
ユーザー情報は、サービス提供に必要な期間保存します。  
退会または削除依頼があった場合、法令上保存が必要な情報を除き、合理的な期間内に削除または匿名化します。  
なお、メール認証が完了していない登録情報は、登録後7日経過時点で自動削除される場合があります。

## 6. 安全管理
取得した情報について、不正アクセス、漏えい、改ざん、滅失、毀損の防止および是正のため、合理的な安全管理措置を講じます。

## 7. ユーザーの権利（開示・訂正・削除）
ユーザーは、自己情報の開示・訂正・削除を希望する場合、下記窓口にご連絡ください。本人確認のうえ、法令に基づき適切に対応します。
