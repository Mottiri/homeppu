# ほめっぷ 子どもの安全基準（CSAE/CSAM対策）

最終更新日: 2026-02-19  
運営者: 早河光洋  
対象サービス: ほめっぷ

## 1. 基本方針
ほめっぷは、児童の性的虐待および搾取（CSAE）を一切許容しません。  
児童性的虐待素材（CSAM）を含む、関連する投稿・画像・動画・コメント・誘導行為を禁止します。

## 2. 禁止事項
以下を含む行為・コンテンツを禁止します。

- CSAMの投稿、共有、保存、要求、勧誘
- 未成年者を対象とした性的なやり取り、性的目的の接触・誘導（グルーミング）
- 児童の性的搾取につながる表現、募集、あっせん、脅迫、強要
- その他、児童の安全を脅かす行為

## 3. 検知と予防
ほめっぷでは以下を実施します。

- 投稿時のシステム簡易チェック
- AIモデレーション
- ユーザーからの通報受付機能

## 4. 違反時の対応
CSAE/CSAMまたはその疑いを把握した場合、運営は以下を実施します。

- 該当コンテンツの非表示・削除
- 該当アカウントの機能制限・停止・BAN
- 必要な記録の保全
- 関連法令および適用されるガイドラインに基づく対応

## 5. 通報窓口（アプリ内）
ユーザーはアプリ内の通報機能・問い合わせ機能から、問題コンテンツを報告できます。

## 6. 法令順守
運営は、適用される児童保護関連法令を順守し、確認されたCSAM等について必要な公的機関への報告手順を整備します。
