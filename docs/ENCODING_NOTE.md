# 文字化け対応メモ（BACKLOG_2025-12-18.md）

## 発生した現象
- `docs/BACKLOG_2025-12-18.md` の「### 31」セクションが文字化け（`???`や不可読文字）した。
- VSCode 上でも同様に文字化けして表示された。

## 原因
- 文字化けした内容をそのまま保存してしまい、**ファイル内容自体が破損**した。
- そのため、エディタの表示設定だけでは復旧できなかった。

## 正しい修正方法
1. 文字化けしているセクションを**丸ごと削除**する。
2. 正しい日本語の内容を**UTF-8**で再入力する。
3. セクション全体を置き換える形で復元する。

## 再発防止ルール
- 文字化けを見つけたら**上書き保存しない**。
- 復旧は必ず**正しい文面をUTF-8で再入力**して置換する。
- 編集後はUTF-8で保存されていることを確認する。

## VSCode 側の対処（必要な場合）
1. `Reopen with Encoding` → `UTF-8`
2. `Save with Encoding` → `UTF-8`
3. それでも表示が崩れる場合は、**フォントが日本語非対応**の可能性を確認する。
