```
S1 (idempotency) → S2 (分散カウンタ) → S3 (フォロー再設計)
                                         → S4 (サークル検索)
                                         → S5 (コメントページネーション)
                                         → S6 (通知カウント)
```

S1-S3 は順番に実施（依存関係あり）。S4-S6 は S3 完了後に並行着手可能。
